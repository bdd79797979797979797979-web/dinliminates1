# CHECKPOINT 1 — Clean Foundation

Branch: `clean-rebuild`

This checkpoint is the recovery point for the first clean-build milestone.

Included:
- iPhone-first dark visual foundation
- Home screen with the approved “what sounds good tonight?” prompt
- Food round with swipe and button actions
- Cut / Maybe / Hide / Back
- Quick Cuts that toggle off and back on
- Quick Cuts operate on primary item/category; secondary ingredients do not inherit a cut
- Saved round persistence in local storage
- Continue saved round
- Manage Foods / Add Food
- Dark winner screen
- Basic restaurant screen shell

Deliberately not included yet:

- restaurant Details
- History / Settings
- Pass Around
